Quick Start

Three ways to use the radar: CLI, MCP Server, or GitHub Actions.

Command Line

# Clone and run git clone https://github.com/VastFuture/new-term-radar cd new-term-radar python -m radar daily --out report.md
  • Install Python 3.10+
  • Set AISA_API_KEY environment variable
  • Copy config.example.json to config.json
  • Run python -m radar daily

MCP Server

# Install from PyPI pip install new-term-radar[mcp] # Or with uvx (no install needed) uvx --with mcp new-term-radar-mcp

Connects to Claude Code, Codex, or any MCP client. Passes AISA_API_KEY as environment variable.

GitHub Actions

# Set repo variables & secrets: # RADAR_ENABLED = true # AISA_API_KEY = your-key # Push config.json (remove from .gitignore first) git add config.json git commit -m "Add radar config"

Sources run every 8h. Daily runs everything including the keyword table. Reports appear in workflow summaries.
